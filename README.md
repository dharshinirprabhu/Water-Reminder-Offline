# 💧 Water Reminder

A lightweight offline Windows desktop application that displays a floating sticker reminder to encourage regular hydration.

## Features

- 🖼️ Displays a custom sticker instead of text notifications
- 📌 Always stays above other applications
- 👆 Click the sticker to dismiss it instantly
- ⏱️ Automatic reminder at customizable intervals
- 📴 Works completely offline
- 🎨 Supports transparent PNG stickers

## Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/water-reminder.git
cd water-reminder
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run:

```bash
python app.py
```
